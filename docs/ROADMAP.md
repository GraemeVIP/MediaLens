# Roadmap

- Desktop 2.2: Brave/Chrome macOS extension, page images, selective channel batches, progress/cancel/retry.
- Android 0.1 beta: standalone paste/share-link download, quality selection, audio and direct images, foreground progress and Downloads integration.
- Next: physical-device validation, Android 16 KB-page native compatibility, signed Android release/update pipeline, Windows/Linux companion installers and more live site regression checks.

Open an issue with a concrete feature or public reproducible example. Stars help people discover the project; bug reports and pull requests make it better.
