# Preserve the user's work

- Leave the current project intact when stopping a task. Never undo work merely because you stop.
- Never discard another contributor's changes or restore an older snapshot without the owner's explicit request.
- Commit existing work before substantial changes. Add commits; do not rewrite published history.
- Do not force-push, delete recovery tags/releases, delete the repository, weaken preservation settings or change visibility without explicit owner authorisation for that action.
- Keep browser profiles, cookies, credentials, companion history and downloaded media outside Git.

These are contributor instructions. GitHub access controls and separate backups provide recovery protection.
